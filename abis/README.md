# Verified ABIs

Vendored ABIs for the active o1 suite on Robinhood Chain (4663). Generated by
`pnpm abi:vendor` (`scripts/vendor-abi.ts`), which fetches each contract from two
independent verification sources, Sourcify and Robinhood Blockscout, and refuses to
write anything unless both ABIs agree.

Per contract:

- `<Name>.<chainId>.<address>.json` — verbatim ABI plus provenance (contract name,
  compiler version, verification timestamp, source URLs).
- `<Name>.<chainId>.<address>.ts` — the same ABI as an `as const` export so viem can
  type function names, arguments and return values.
- `index.ts` re-exports `launchFactoryAbi`, `launchHookAbi`, `feeEscrowAbi`,
  `launchTokenDeployerAbi`.

Do not edit these files by hand. When `pnpm o1:sync` reports registry drift, re-run
`pnpm abi:vendor`, keep the previous files (historical factories stay authoritative for
the tokens they created), and re-derive the allow-list selectors in
`packages/shared/src/tx-allowlist.ts` from the new ABI.

The launch-buy adapter (`contracts.launchBuyAdapter`) is not source-verified on any
explorer, so it is not vendored. Its `routeData` layout is reverse-engineered from live
calldata and pinned by `packages/executor/test/route.test.ts`.
